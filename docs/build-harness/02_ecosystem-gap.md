# Ecosystem Gap

## Ecosystem

FalkorDB graph database and graph-native AI agent tooling.

## Gap

The ecosystem provides fast Cypher traversal and graph storage, but the sampled hackathon field lacks a narrow, executable food-recall workflow with policy gates, evidence receipts, and replay-safe actions.

## Dependency

FalkorDB is load-bearing for direct lineage, shared-equipment exposure, distribution reachability, persistent case state, approval records, and action receipts. The complete proof ran on a real FalkorDB Cloud graph; the deterministic memory adapter remains only for offline development and regression tests.

## Portability

The workflow could be built on another graph database. FalkorDB is suitable because the hackathon requires it and because graph traversal is the load-bearing operation, but no unique FalkorDB-only primitive is claimed.

## Alternatives

| Alternative | Strength | Limitation addressed here |
|---|---|---|
| Spreadsheet reconciliation | Familiar | Weak multi-hop reachability and audit trail |
| Broad SKU/date recall | Simple | Can over-recall unrelated lots |
| Generic GraphRAG | Flexible Q&A | Does not necessarily enforce policy or execute safely |

## Thesis

LotLine contributes a reusable pattern for graph-backed operational agents: fixed traversal tools, deterministic policy, human approval, idempotent effects, and evidence paths.
